# Product Proposal

## 1. Обоснование идеи
Рынок труда в эпоху ИИ меняется постоянно, поэтому каждому специалисту необходим быть в курсе трендов рынка труда, учить необходимые навыки, которые указывают в своих вакансиях и регулярно обновлять свое резюме.

## 2. Цель и метрики
Поэтому прикладная задача: сделать сервис, которые по нажатию сам проследил в тренды рынка труда, получать аналитику по резюме и обновлять его

| Тип метрики | Метрика (KPI) | Целевое значение |
| :--- | :--- | :--- |
| **Продуктовая** | Релевантность вакансий (оценка пользователя) | > 85% |
| **Техническая** | P95 Latency (полный цикл) | < 150 секунд |
| **Бизнес** | Стоимость обработки 1 кандидата | ~ 15 рублей за отчет |

## 3. Сценарии использования
* **Стандартный:** "Проверь мое резюме [ссылка] и найди работу в Мск на 300к+".
* **Смена стека:** "Я аналитик, хочу в DS. Что мне доучить и какие есть вакансии для джунов?".
* **Анализ рынка** "Какие компании сейчас больше нанимают: финтех, ритейл, промышленность и тд."

## 4. Ограничения
* **Технические:** Лимиты API DeepSeek (TPM/RPM)
* **Операционные:** Бюджет на разработку PoC — до 10000 рублей (API + Compute + на раскатку на сервере).
* **Данные:** База вакансий обновляется в ручную
