# Ключевые архитектурные решения (ADR)

** Оркестрация (State Machine): ** Выбран LangGraph. В отличие от линейных цепочек, граф позволяет реализовать циклическую логику и четкое разделение ответственности между узлами (Nodes).

** LLM (Core): ** DeepSeek-V3 (через API). Оптимальное соотношение "цена/качество" для сложных задач классификации и генерации структурированных планов.

** Retrieval (RAG):** Гибридный поиск. FAISSa4w2 для векторного поиска по эмбеддингам и Polars для фильтрации структурированных данных (зарплаты, локации).

** Память: ** MemorySaver (In-memory) для PoC. Постоянной и важной информации о пользователе не хранится, так что достаточно просто истории диалога в сессии.
